## 🎯 Core Focus Areas & Programs

1. **Child Education & Literacy:** Free homework guidance, study material distribution, notebook drives, and foundational schooling support in Madanpur Khadar and Delhi NCR clusters.
2. **Women's Skill & Tailoring Training:** Vocational tailoring centers, cutting and stitching workshops, and economic self-reliance programs for adolescent girls and mothers.
3. **Digital & Computer Literacy:** Practical training on computers, typing, document processing, and internet utilities.
4. **Health, Sanitation & Nutrition Awareness:** Community drives educating families on maternal hygiene, sanitation, and balanced nutrition.
5. **Community Welfare & Human Rights:** Addressing grassroots welfare grievances, elder engagement, and relief solidarity during regional distress.

## 📱 Mobile-First Architecture & Conversions

* **Mobile Sticky Quick-Action Dock:** Persistent bottom action dock on mobile screens (`sm:hidden`) providing instant access to:
  * 📞 **Direct Call** (`tel:+919555537474`)
  * 💬 **Instant WhatsApp Chat** (`wa.me`) with pre-filled enquiry message
  * ❤️ **Support & Volunteer Action**
* **Instant WhatsApp Redirection:** The website enquiry form immediately redirects user input directly to WhatsApp with pre-filled details, removing friction for instant communication.
* **Responsive 3D Lay-Flat Ledger:** Interactive 3D Educational Ledger with realistic 170° lay-flat pages, tricolour ribbons, and a toggleable "Official Campaign" tab preview.
* **Zero AI Media Policy:** 100% authentic archival campaign art, training center photography, and registered organizational logos.

## 🚀 Getting Started

### Prerequisites
* Node.js 18+
* npm 9+

### Installation
```bash
# Clone the repository
git clone https://github.com/solvanetechnologies/SCP-Foundation-NGO.git
cd SCP-Foundation-NGO

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
